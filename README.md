# iOS→Web Harness MVP

这是一个计划在 1～2 天内验证价值的轻量 iOS→Web Harness。

它不追求一次迁移完整 App，也不建设通用 Agent 平台。首个目标是：选择一个真实、可运行的 iOS 项目，把其中一个小功能迁移为 Web，并完成自动验证和人工验收。
