# 项目清单

从这里选择源项目，再打开蓝图选择功能。用户和 AI 共用同一份蓝图。

| 源 iOS 项目 | 项目蓝图 | 当前功能状态 | WebApp 成果 |
| --- | --- | --- | --- |
| `eCommerce-main` | [打开项目蓝图](项目/ecommerce-main/项目蓝图.md) | 个人资料、分类入口、子分类、单列商品列表和购物车已用 Pixelmatch + SSIM 复验；详情待精修 | [查看 WebApp](WebApp查看清单.md) |

## 使用方法

1. 在上表中找到源 iOS 项目；
2. 打开该项目的 `项目蓝图.md`；
3. 从功能分布表中选择尚未迁移或需要调整的功能；
4. 告诉 AI：`迁移 <项目名称> 蓝图中的 <功能名称>`；
5. 完成后打开 `WebApp查看清单.md` 验收。
