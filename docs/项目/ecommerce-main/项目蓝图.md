# eCommerce-main 项目蓝图

> 用途：用户查看功能范围，AI按同一张表定位源码并逐模块迁移。更新时间：2026-08-17。当前实验分支的 WebApp 已清空。

## App 功能地图

```text
eCommerce-main
├── 认证：登录、注册、重置密码
├── 首页：轮播图、折扣商品、新品
├── 商店
│   ├── 分类入口
│   ├── 子分类
│   ├── 商品列表
│   └── 商品详情
├── 收藏
├── 购物车
├── 结账与支付
├── 订单
└── 个人资料
```

## 功能与源码

| 功能 | 用户入口 | 关键源码 | 主要依赖 | iOS 状态 | Web 状态 |
| --- | --- | --- | --- | --- | --- |
| 登录 / 注册 | 启动 App | `SignInView`、`SignUpView`、`AuthenticationManager` | Firebase Auth | 登录已验证 | 实验分支待重建 |
| 首页轮播 / 折扣 / 新品 | Home Tab | `HomeView`、`HomeViewModel` | 商品与折扣数据 | 源码已发现 | 实验分支待重建 |
| 分类入口 | Store Tab | `StoreView`、`StoreRowView` | 分类枚举、原分类图片 | 已运行验证 | 实验分支待重建 |
| 子分类 | 点击 Clothing 等分类 | `CategoriesListView`、`Category.swift` | 分类枚举 | 已运行验证 | 实验分支待重建 |
| 商品列表 | 点击 All 或子分类 | `ProductsListView`、`ProductCellView`、`ProductsViewModel` | ProductManager | 已运行验证 | 实验分支待重建 |
| 商品详情 | 点击商品 | `ProductDetailView` | Product、Discount | 已观察，证据待归档 | 实验分支待重建 |
| 收藏 | Favorites Tab / 商品按钮 | `FavoritesView`、`FavoriteProductsViewModel` | Firebase 用户数据 | 源码已发现 | 实验分支待重建 |
| 购物车 | Cart Tab / Add to Cart | `CartView`、`CartViewModel`、`AddToCartViewModel` | Firebase 用户数据 | 已运行验证 | 实验分支待重建 |
| 结账 / 支付 | 购物车进入 | `CheckoutView`、`CheckoutViewModel` | Stripe、Firebase | 源码已发现 | 实验分支待重建；外部服务不可用时如实记录 |
| 订单 / 个人资料 | Profile Tab | `ProfileView`、`OrdersViewModel` | Firebase 用户数据 | 个人资料已运行复验 | 实验分支待重建 |

## 商店调用关系

```text
StoreView
├── All ───────────────────────→ ProductsListView
└── 主分类 → CategoriesListView → ProductsListView
                                      ↓
                               ProductDetailView
                                      ↓
                         收藏 / 加入购物车
```
