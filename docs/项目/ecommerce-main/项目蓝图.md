# eCommerce-main 项目蓝图

用途：让用户选择迁移范围，让 AI 对账页面和状态。页面候选来自源码；导航与依赖必须由 codebase-memory 确认；空/有数据等运行状态由源码与必要的 iOS 运行共同确认。

> 当前 Run：`20260822-104706-full-app`。事实锁版本 4；功能、移动外壳和视觉证据均已重跑。当前自动状态为 `NEEDS_REVISION`，原因是首页视觉仍建议人工检查。

## App 结构

```text
登录 / 注册 / 重置密码
          ↓
五栏主界面
├─ Home：首页 → 商品
├─ Store：分类 → 商品列表 → 商品详情
├─ Favorites：收藏 → 商品详情
├─ Cart：购物车 → 结账 → 订单确认
└─ Profile：个人资料 → 编辑资料 / 地址 / 账号 / 订单详情
```
