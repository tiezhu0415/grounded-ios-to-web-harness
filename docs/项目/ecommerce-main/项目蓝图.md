# eCommerce-main 项目蓝图

> 用途：你从这里选择下一项迁移功能；AI 用同一份表定位源码。更新时间：2026-08-14。

## App 功能地图

```text
eCommerce-main
├── 认证：登录、注册、重置密码
├── 首页：轮播图、折扣商品、新品
├── 商店
│   ├── 分类入口
│   ├── 子分类
│   ├── 商品列表
│   └── 商品详情
├── 收藏
├── 购物车
├── 结账与支付
├── 订单
└── 个人资料
```

## 商店调用关系

```text
StoreView
├── All ───────────────────────→ ProductsListView
└── 主分类 → CategoriesListView → ProductsListView
                                      ↓
                               ProductDetailView
                                      ↓
                         收藏 / 加入购物车
```
