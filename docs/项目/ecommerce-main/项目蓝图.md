# eCommerce-main 项目蓝图

用途：让用户看到 App 有哪些功能，让 AI 检查迁移有没有遗漏。页面范围来自 iOS 源码，具体依赖由 codebase-memory 在实施时确认。

> 旧 WebApp 与 Run 已隔离。下面是本次迁移的功能范围，不代表已经实现；新 Run 必须重新扫描、对账和验证。

## App 结构

```text
登录 / 注册 / 重置密码
          ↓
五栏主界面
├─ Home：首页 → 商品
├─ Store：分类 → 商品列表 → 商品详情
├─ Favorites：收藏 → 商品详情
├─ Cart：购物车 → 结账 → 订单确认
└─ Profile：个人资料 → 编辑资料 / 地址 / 账号 / 订单详情
```
