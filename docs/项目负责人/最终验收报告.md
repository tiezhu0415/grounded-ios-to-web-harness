## 差异说明

1. **数据源**：源 App 从 Firestore 读取；WebApp 使用 `ProductDatabase.swift` 的本地静态数据。
2. **图片**：继续使用 Firebase Storage URL，未迁移图片资源。
3. **交互**：WebApp 未实现商品详情页、收藏、加入购物车；点击商品卡片无跳转。
4. **搜索**：WebApp 保留了搜索框用于触发空状态，但不属于源功能迁移目标。
5. **布局**：从 iOS SwiftUI 两栏卡片改为响应式网格卡片。
