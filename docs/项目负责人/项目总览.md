# 项目总览

## 一句话目标

用 1～2 天把一个真实 iOS App 的一个小功能迁移为 Web，并用测试证明结果，判断 Harness 是否值得继续。

## 整体流程

```text
跑通 iOS App
    ↓
生成全项目简明蓝图
    ↓
你选择一个功能
    ↓
详细分析这个功能
    ↓
Spec Kit 制订计划
    ↓
Claude 实现 WebApp
    ↓
Playwright 验证
    ↓
你最终验收
```

## 工具分工

| 工具 | 用途 | 首版是否使用 |
| --- | --- | --- |
| Git | 固定源项目 commit | 是 |
| Xcode / xcodebuild / simctl | 构建、安装和启动 iOS App | 是 |
| codebase-memory-mcp | 分析模块、符号、依赖和调用关系 | 是 |
| Claude | 整理蓝图、制订方案、实现 WebApp | 是 |
| Spec Kit | 把获批功能转换为实现任务 | 是 |
| React + TypeScript | 实现目标 Web 功能 | 是 |
| Playwright | 验证 Web 行为 | 是 |
| Codex | 用户按需进行独立审查 | 可选 |
| Maestro | 重复验证 iOS 流程 | 首版默认不用 |
| 自研 Swift analyzer | 文件和声明扫描 | 不做 |
