### 数据模型

```swift
struct Product: Identifiable, Codable, Equatable {
    let id: String
    let name: String
    let price: Double
    let brand: String
    let gender: String
    let category: String      // MasterCategory.rawValue
    let subCategory: String   // SubCategory.rawValue
    let description: String
    let sizes: [String]
    let variants: [ProductVariant]
    let isDiscounted: Bool?
    let isNewIn: Bool?
}

enum MasterCategory: String, CaseIterable {
    case clothes = "Clothing"
    case shoes = "Shoes"
    case accessories = "Accessories"
}

enum SubCategory: String, CaseIterable { ... } // 每个子分类通过 masterCategory 关联主分类
```

### 调用关系

```text
StoreView (State: searchText, selectedCategory, isSelectingAll/Category)
    → CategoriesListView(category)
        → ProductsListView(category, subCategory)
            → ProductsViewModel.getProducts()
                → ProductManager.getProducts(forCategory:subcategory:withDiscount:isNewIn:count:lastDocument:)
                    → Firestore Query + Query+Extension.getDocumentsWithSnapshot(as:)
    → ProductsListView(nil, nil)  // "All" 入口
```

### 状态

- `ProductsViewModel.products: [Product]`：当前已加载的商品列表
- `ProductsViewModel.lastDocument: DocumentSnapshot?`：Firestore 分页游标
- `ProductsViewModel.discounts: [Discount]`：全局折扣信息，用于卡片展示折扣标签
- `ProductsViewModel.category/subCategory`：当前筛选条件
- `ProductsViewModel.showDiscountedProducts / showNewInProducts`：特殊筛选开关（由 Home 入口使用）

### 用户操作

| 操作 | 结果 |
| --- | --- |
| 点击 Store Tab | 进入 StoreView，看到 Clothing/Shoes/Accessories 分类入口 |
| 点击 "All" | 进入 ProductsListView，展示全部商品，每页 10 条，滚动到底部加载下一页 |
| 点击某个主分类 | 进入 CategoriesListView，列出该分类下的子分类 |
| 点击子分类 | 进入 ProductsListView，按 `category` + `subCategory` 过滤 |
| 滚动列表 | 触发 `ProgressView.onAppear { viewModel.getProducts() }` 分页加载 |
| 点击商品卡片 | 进入 `ProductDetailView`（**本次不包含**） |
